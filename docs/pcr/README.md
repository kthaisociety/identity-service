# Project convention records

A PCR records a convention for the **whole project**: something every change is expected to follow. For
decisions about one part of the code, see [`../adr/`](../adr/).

- One file per convention, numbered: `NNNN-short-title.md`. Never renumber or delete one; a convention
  that changes gets a new PCR, and the old one's status becomes `Superseded by NNNN`.
- Status: `Proposed`, `Accepted`, or `Superseded by NNNN`.
- Keep them short: Convention, Why, How to apply.
