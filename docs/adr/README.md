# Architecture decision records

An ADR records a decision about **one part** of the code: what was decided, why, and what it costs. For
conventions that apply to the whole project, see [`../pcr/`](../pcr/).

- One file per decision, numbered: `NNNN-short-title.md`. Never renumber or delete one; a decision that
  changes gets a new ADR, and the old one's status becomes `Superseded by NNNN`.
- Status: `Proposed` (open, still to decide), `Accepted`, or `Superseded by NNNN`.
- Keep them short: Context, Decision, Consequences.
