# 0006. OIDC implementation: open

Status: Proposed

## Context
ADR 0004 says what the service speaks (OIDC, auth code with PKCE). It doesn't say how it's built.

## Decision
Not decided. Explore the options, then record the choice and the reasons in a new ADR that supersedes
this one.

## Consequences
Whatever is chosen must keep the service small and readable for the next team.
