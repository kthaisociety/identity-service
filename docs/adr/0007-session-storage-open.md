# 0007. Sign-in session storage: open

Status: Proposed

## Context
Single sign-on (ADR 0004) means identity remembers who is signed in, so the next app doesn't send the
user to Google again. Sign-out ends that session.

## Decision
Not decided: where the session lives, how long it lasts, and how sign-out works. Record the choice in a
new ADR that supersedes this one.

## Consequences
None yet.
